# Native Turkish benchmark expansion template

This is a blank collection template, not benchmark data. Each item must be
written independently by a native-Turkish annotator; do not translate an
English seed and do not use model-generated text as a final item.

Two annotators record labels without seeing one another’s answer. An adjudicator
records the final label and any rationale. Before freezing a batch, calculate
raw agreement and Cohen’s kappa by task family, then copy only adjudicated,
approved records into the frozen benchmark.
