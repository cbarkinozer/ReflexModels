# Tokenizer fertility corpora

These files are deliberately small, hand-authored smoke-test corpora. They
cover conversational, formal, developer, and Turkish-English technical text.
They are not training or benchmark data and must not be used to claim model
quality. Replace them with separately documented, license-verified corpora
before making a backbone-selection decision.

Each JSONL record contains only a `text` field to keep the tokenizer benchmark
independent of task labels.
